##  Telco Customer Churn Analysis

Ce projet analyse les données clients d’une entreprise de télécommunications afin d’identifier les raisons du désabonnement (churn) et de proposer des **mesures business** pour améliorer la fidélisation.

##  Objectifs
 Déterminer les facteurs clés du churn (contrat, mode de paiement, type de service…)
 Identifier le profil client le plus à risque
Proposer des actions ciblées pour réduire le taux de désabonnement.

##  Technologies utilisées
Python (pandas, numpy, matplotlib, seaborn, scikit-learn)
Jupyter Notebook pour l’analyse exploratoire
